# Roadmap

In order of priority. Each step is done completely before the next begins.

## Before a public launch

1. **Verify against the Guide.** Supply the Business management guide; run the procedure in CURRICULUM_MAPPING.md; mark verified lines `primary`.
2. **Upgrade Astro to 7.4** on Node 24 (SECURITY.md), and set a Content Security Policy.
3. **Deploy** as a separate Vercel project (DEPLOYMENT.md) and check the live site.
4. **Accessibility testing with people** who use screen readers, magnification and switch access; test in Firefox and Safari and on real phones.
5. **Confirm the use** of command term definitions quoted from the IB Economics guide (SOURCE_GOVERNANCE.md).
